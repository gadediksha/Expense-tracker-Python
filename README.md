## 💸 Expense Tracker (Python)

A simple and user-friendly console-based Expense Tracker built using Python.  
This project helps users record daily expenses, view all spending, and calculate total costs easily.

---

## 📌 Features

✅ Add new expenses  
✅ View all expenses  
✅ Calculate total spending  
✅ Simple menu-driven interface  
✅ Beginner-friendly Python project  

---

## 🛠️ Technologies Used

- 🐍 Python  
- 📚 Basic Data Structures (List & Dictionary)  
- 💻 Console / Terminal  

---

## ▶️ How to Run the Project

1. Clone or download this repository  
2. Open the folder  
3. Run the file using:

python expense_tracker.py

4. Follow the on-screen menu options  

---

## 📋 Menu Options Explained

1️⃣ Add a new expense  
2️⃣ View all expenses  
3️⃣ View total spending  
4️⃣ Exit the program  

---

## 🧠 Project Concept

This project uses:

- List of Dictionaries  
- Loops & Conditions  
- User Input Handling  
- Basic Calculations  

Each expense is stored like this:

date, category, description, amount
